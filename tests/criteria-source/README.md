# מקור בנק הקריטריונים

הקבצים כאן הם המקור ממנו נבנה בלוק `DATA` שבתוך `ביקורות-הדרכה.html` —
תעתיק של מסמך "פירוט הקריטריונים לביקורת 1.9" (29 עמודים), קריטריון-קריטריון,
כולל נוסח כל אפשרות תשובה והציון שלה.

`gph.py` · `prog.py` · `cmd.py` · `trainee.py` — ממד לכל קובץ.
`footnotes.py` — 42 הערות השוליים של המסמך: לכל אחת מספרה, הקריטריון/האפשרות
שאליה היא שייכת, **המילה** שאליה נצמד המספר במסמך, ונוסח ההערה.
`build.py` — משבץ את ההערות, מריץ ולידציה ומייצר `DATA.js` להטמעה בקובץ ה-HTML.
הוולידציה נכשלת אם מילת העוגן אינה קיימת בטקסט או מופיעה בו יותר מפעם אחת.

```bash
cd tests/criteria-source && python3 build.py
```

**האפליקציה אינה קוראת את הקבצים האלה בזמן ריצה** — `DATA` מוטמע בקובץ ה-HTML עצמו.
הם נשמרים כאן כדי שעדכון עתידי של מסמך הקריטריונים יהיה עריכה של טקסט מובנה
במקום עריכה ידנית בתוך HTML של 4,600 שורות.
